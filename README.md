# Restaurant-Menu
Responsive restaurant menu website using html,css featuring the food images, categorized dishes and hover  animations .
🍽️ The Royal Table — Restaurant Daily Menu

A clean, elegant, and responsive restaurant menu website built using HTML and CSS. The project presents a digital daily menu with categorized food items, images, descriptions, prices, and interactive hover effects.

✨ Features

- 🍴 Categorized menu sections
- 🥗 Appetizers, Main Course, Drinks & Desserts
- 🖼️ Food images for every menu item
- 💰 Clearly displayed prices
- ✨ Hover animations and image zoom effects
- 📱 Responsive design for mobile and desktop
- 🎨 Clean and modern restaurant-themed UI
- ⚡ Lightweight and easy to run

🛠️ Technologies Used

- HTML – Website structure and semantic elements
- CSS – Styling, Flexbox, responsive design, and animations

📂 Project Structure

Restaurant-Daily-Menu/
│
├── index.html
├── style.css
└── README.md

🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open "index.html" in any web browser.
4. The restaurant menu will be displayed.
